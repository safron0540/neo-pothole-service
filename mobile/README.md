# NEO-СЕРВИС: Ямочный ремонт — мобильное приложение (каркас)

Стек: React Native + TypeScript, Expo, React Navigation.

## Запуск
```
npm install
npx expo start
```
Откройте QR-код в приложении Expo Go на Android-телефоне (телефон и компьютер в одной сети).
Камера, геолокация и карта работают в Expo Go. Push и сборка APK — через development build (EAS).

## Что готово
- Вход, регистрация (два согласия, проверка пароля), карта с цветными маркерами,
  «Мои заявки», детали заявки, экран «Новая заявка» с камерой.
- Авторизация, отправка фото и заявок, список и детали заявок подключены к API стенда.

## Структура
`src/theme` — цвета, статусы (УД-2) · `src/utils` — даты UTC+7, валидаторы ·
`src/screens` — экраны · `src/components` — общие элементы · `src/navigation` — маршруты ·
`src/api` — клиент запросов и преобразование ответов API · `src/types` — типы приложения.

## Бэкенд
По умолчанию приложение использует стенд `https://pothole.safronspace.ru/api/v1`.
Чтобы указать другой сервер, задайте `EXPO_PUBLIC_API_URL` в `.env` (см. `.env.example`).
Тайлы карты запрашиваются у того же сервера по `/tiles/{z}/{x}/{y}.png`.
Стенд сейчас возвращает `501 Not Implemented` для регистрации, входа, проверки фото,
создания заявок и их списка. После реализации этих методов на сервере подключённые экраны
начнут получать реальные данные без дополнительных изменений URL в приложении.
