# NEO-СЕРВИС: Ямочный ремонт — мобильное приложение (каркас)

Стек: React Native + TypeScript, Expo, React Navigation.

## Запуск
```
npm install
npx expo start
```
Откройте QR-код в приложении Expo Go на Android-телефоне (телефон и компьютер в одной сети).
Камера, геолокация и карта работают в Expo Go. Push и сборка APK — через development build (EAS).

## Что готово
- Вход, регистрация (два согласия, проверка пароля), карта OSM с цветными маркерами,
  «Мои заявки», детали заявки, экран «Новая заявка» с камерой.
- Все данные пока из `src/mocks`, авторизация — заглушка (`src/store/AuthContext.tsx`).

## Структура
`src/theme` — цвета, статусы (УД-2) · `src/utils` — даты UTC+7, валидаторы ·
`src/screens` — экраны · `src/components` — общие элементы · `src/navigation` — маршруты ·
`src/mocks`, `src/types` — временные данные и типы (заменить на OpenAPI).
