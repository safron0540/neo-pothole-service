## Проверено, замечаний нет

- **Роли.** Каждый эндпоинт, кроме входа, регистрации, refresh, health и фото по подписи, требует роль (`require()` в `app/deps.py`). Чужая заявка: гражданину и подрядчику отвечаем 404 (тесты `test_foreign_*`, `test_other_citizen_*`). Подать заявку с чужим фото нельзя (`foreign_photo`).
- **Схемы ответа по ролям.** Подрядчик не видит телефон заявителя, гражданин не видит внутренние заметки.
- **Пароли и токены.**
  - Пароли хранятся как argon2. Сложность пароля проверяется (БЗ-3).
  - Access-токен живёт 30 минут. Refresh-токен живёт 14 дней и меняется при каждом обновлении.
  - В базе лежит только SHA-256 от refresh-токена. Повторное использование отозванного токена отзывает все токены пользователя.
- **SQL.** Все значения передаются параметрами. В f-строках подставляются только константы кода (`POINT` и имена таблиц в `as_geojson`).
- **Фото.** Принимаются только JPEG и PNG: формат определяется по содержимому, а не по имени файла. Размер — до 10 МБ (nginx пускает 11 МБ). Пиксели API не раскодирует, только `verify`. Отдаётся фото по подписи HMAC со сроком 15 минут; подделанная подпись даёт 403.
- **Логи.** Пароли, токены и телефоны в лог не пишутся. nginx пишет путь без query: там подпись фото.
- **Наружу.**
  - Открыт только nginx на 127.0.0.1:8080, перед ним Caddy с HTTPS.
  - База, backend, ML, Prometheus и Grafana слушают только localhost.
  - `/metrics` снаружи закрыт.
  - Есть заголовки `X-Content-Type-Options`, `X-Frame-Options` и `Referrer-Policy`; HSTS выставляет Caddy.
- **Секреты в Git.** Только `.env.example`. В `.gitignore` есть `.env`, `secrets/` (ключ Firebase), `backups/` и `deploy.sh`.
- **Push.** Ключ Firebase лежит в файле вне Git. Токены устройств в лог не попадают. Мёртвые токены удаляются.

## Что сделать на сервере (человеку)

1. Переписать `.env` по `.env.example`:
   - свой `JWT_SECRET` (не короче 32 символов);
   - `POSTGRES_PASSWORD`;
   - `GRAFANA_PASSWORD`;
   - `CORS_ORIGINS` с доменом веба.

   Без этого API после деплоя не запустится. Так и задумано.
2. Caddy: проксировать домен на `127.0.0.1:8080` (nginx).
3. Поставить в crontab ночную чистку и `backup.sh` (README). Копии хранить ещё где-то, кроме этого сервера.
