## Что блокирует

1. **Порог покрытия в быстром job CI.** С PR 2-2 он не проходит: сервисы покрыты интеграционными тестами, а `backend-ci` считает покрытие без базы. Предложено Егору считать покрытие в `backend-integration`.
2. **Деплой на сервер:** нужно переписать серверный `.env` по `.env.example` (свой `JWT_SECRET`, `ENVIRONMENT=prod`) и один раз прогнать `deploy.sh`; узнать у Егора, куда Caddy отправляет `/api`.
