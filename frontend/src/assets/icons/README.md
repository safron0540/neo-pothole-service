# Иконки из Figma

Положите сюда SVG-файлы с точными именами из таблицы (расширение `.svg`). Пока файла нет, на месте иконки пустой блок; в консоли (`npm run dev`) выводится, каких файлов не хватает.
После добавления файлов перезапустите `npm run dev`. В консоли браузера (F12) будет строка вида `[Icons] найдено 75 из 75 иконок`; опечатки в именах файлов выводятся предупреждением.

Как экспортировать: откройте ссылку, выделите иконку (внутри групп — Ctrl/Cmd + клик), справа внизу **Export → SVG**, потом переименуйте файл.
Иконки меню берутся из кадра «Веб/План» (бок. меню), вкладок админки — из кадра «Веб/Админ_сроки» (иконка слева от названия вкладки).
