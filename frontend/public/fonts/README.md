# Шрифт Circe

Макет использует шрифт **Circe**. Здесь лежат его файлы в формате WOFF2:

| Файл                    | Начертание      | Где используется                      |
|-------------------------|-----------------|---------------------------------------|
| `Circe-Light.woff2`     | Light (300)     | Caption, 12 px                        |
| `Circe-Regular.woff2`   | Regular (400)   | Body, 14 px                           |
| `Circe-Bold.woff2`      | Bold (700)      | H1 24 px, H2 18 px, кнопки            |
| `Circe-ExtraBold.woff2` | Extrabold (800) | крупные числа                         |
| `Circe-Thin.woff2`      | Thin (100)      | не используется, оставлен для полноты |

Подключение — в `src/index.css` (`@font-face`). Если Circe установлен на компьютере, браузер возьмёт системный.

**Лицензия.** Circe — коммерческий шрифт. Убедитесь, что у проекта есть лицензия на веб-использование
(при её отсутствии замените на бесплатный аналог, например Nunito Sans, и поправьте `font-family`).
