NEO-СЕРВИС: Ямочный ремонт (Frontend)

Клиентская часть веб-приложения для автоматизации процессов регистрации,
распределения и контроля выполнения работ по ямочному ремонту дорожного полотна
в соответствии с нормативами ГОСТ Р 50597-2017.

Реализованный функционал

1. Интерфейс диспетчера

  - Очередь входящих заявок: сортировка по приоритету ГОСТ (остаток времени на
    устранение) и по дате поступления.
  - Карточка дефекта: просмотр адреса, геокоординат, параметров дефекта
    («Большая» / «Маленькая» яма), привязки к категории дороги и назначенного
    подрядчика.
  - Обработка заявки: смена статусов («Принято», «Отклонено», «Запрос
    уточнения»), добавление служебных заметок.

2. Картографический модуль (ГИС)

  - Интерактивная карта: интеграция с Leaflet и тайлами OpenStreetMap.
  - Слои визуализации:
      - Маркеры дефектов с цветовой дифференциацией по статусам жизненного
        цикла.
      - Тепловая карта (leaflet.heat) для анализа плотности и концентрации
        повреждений.
      - Полигоны зон ответственности подрядных организаций.
  - Фильтрация: по статусу, району, категории улицы, классу дефекта и
    подрядчику.
  - Превью заявки: модальная карточка объекта на карте с переходом к полной
    карточке.

3. Модуль планового ремонта

  - Анализ плотности дефектов: учет участков с превышением лимита ям на 100
    метров полотна.
  - Отображение отрезков: рендеринг проблемных участков дорог через векторные
    линии (Polyline).
  - Принятие решений: выбор между сохранением точечного ремонта и включением
    участка в программу сплошной замены покрытия.

4. Кабинет подрядчика

  - Список нарядов: фильтрация по статусам («Все», «В работе», «Просроченные»,
    «Выполнено»).
  - Карточка наряда: данные осмотра, класс ямы, GPS-координаты, фотофиксация до
    ремонта.
  - Закрытие заявки: загрузка контрольного фото после проведения работ и смена
    статуса на «Выполнено».

5. Аналитика и отчетность

  - Метрики эффективности: расчет общего числа дефектов, доли устраненных в срок
    и среднего времени выполнения работ.
  - Сводная ведомость: таблица показателей по районам и подрядчикам.
  - Экспорт: генерация и выгрузка отчетов в формате Excel (.xlsx) на стороне
    клиента с помощью библиотеки xlsx.

6. Администрирование и пользователи

  - Нормативы сроков: настройка предельного времени устранения (в часах) для
    дорог категорий «А», «Б» и «В».
  - Реестр улиц: справочник классификации дорог с распределением по районам.
  - Управление доступом: список учетных записей, фильтрация по ролям, добавление
    и деактивация пользователей.

Стек технологий

  - Фреймворк: React 19, TypeScript
  - Сборка: Vite 8
  - Стилизация: Tailwind CSS 3
  - Картография: Leaflet, React-Leaflet, Leaflet.heat
  - Иконки: Lucide React
  - Экспорт данных: SheetJS (xlsx)
  - Линтинг: Oxlint

Установка и запуск

Требования

  - Node.js >= 20.19.0
  - npm >= 9.x

Установка зависимостей

npm install

Запуск dev-сервера

npm run dev

Приложение доступно по адресу http://localhost:5173.

Сборка проекта

npm run build

Результат сборки помещается в директорию dist/.

Проверка кода

npm run lint

Тестовые учетные записи

На странице авторизации реализован быстрый вход для проверки ролевой модели:

  - Диспетчер: логин по умолчанию или кнопка «Диспетчер (Иванова)». Доступны все
    разделы системы, включая ГИС, отчеты и администрирование.
  - Подрядчик: логин, содержащий contractor / voronov, или кнопка «Подрядчик
    (Воронов)». Доступен интерфейс исполнения нарядов.
  - В нижнем правом углу экрана доступен переключатель ролей для тестирования
    интерфейсов без повторной авторизации.
